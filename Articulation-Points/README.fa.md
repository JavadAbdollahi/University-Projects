## 📖 مسئله چیست؟

**نقطه‌ی محوری (رأس برشی)** در یک گراف بدون جهت، رأسی است که حذف آن تعداد مؤلفه‌های همبندی گراف را افزایش می‌دهد. یافتن این نقاط در تحلیل شبکه‌های ارتباطی، قابلیت اطمینان شبکه و درک ساختار گراف کاربرد دارد.

## ⚙️ الگوریتم چگونه کار می‌کند؟

از **جستجوی عمق اول (DFS)** استفاده می‌کنیم و برای هر رأس `u` دو مقدار محاسبه می‌کنیم:

- `DFNum(u)`: زمان ملاقات (ترتیب) رأس `u` در حین DFS.
- `Low(u)`: کوچک‌ترین `DFNum` قابل دسترس از `u` با استفاده از یال‌های درختی یا حداکثر یک یال برگشتی.

سپس یک رأس غیر ریشه `u`، نقطه‌ی محوری است اگر فرزندی `v` داشته باشد به طوری که:

    ```
    Low(v) ≥ DFNum(u)
    ```


ریشة درخت DFS نیز نقطه‌ی محوری است اگر **بیش از یک فرزند** داشته باشد.

زمان اجرای الگوریتم **O(V + E)** است.
